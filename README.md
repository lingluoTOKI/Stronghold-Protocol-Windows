## ✨ 亮点

- **对战聊天 + 表情**：文字/表情混发，面板可折叠、可拖拽、终端风 UI，适配手机输入法
- **战斗倍速 1×/2×/4×**：切换不跳变，倒计时与倍速同步
- **服务器匹配队友**：创建同盟可选 2/3/4 人匹配，支持 AI 补位、房主踢人
- **跳过本场**：敌人全部出场后可直接结算进入下一轮
- **实时在线监控**：`/api/online`、`/api/status` 接口
- **完整电脑快捷键**（见下）

## ⌨️ 电脑快捷键

| 键 | 动作 | 生效阶段 |
|---|---|---|
| `Esc` | 关闭 / 取消 | 全局 |
| `R` | 刷新商店 | 整备 |
| `F` | 冻结商店（下回合保留） | 整备 |
| `D` | 升级调度中心 | 整备 |
| `S` | 出售当前选中干员 | 整备 |
| `B` | 快速购买（点选商店格子后按 B） | 整备 |
| `Q` | 撤退选中干员回备战区 | 整备 |
| `X` | 倍速 1×/2×/4× 循环 | 战斗 |
| `E` | 聊天 / 表情面板开合 | 全局 |
| `空格` | 准备就绪 / 暂停战斗 | 整备 + 战斗 |

> 快捷键在输入框 / 弹窗打开时自动让路（不会误触），长按也不会连发。

## 🚀 快速开始

- **本机开服**：双击 `本机当服务器.bat`，把打印出的局域网地址发给朋友即可加入
- **连接别人**：双击 `连接服务器.bat`，用浏览器打开对方的服务器
- **免安装**：内置便携 Node，目标机无需安装任何东西、不访问外网
- 解压后双击 `启动游戏.bat` 进入启动器菜单（本机当服务器 / 连接服务器 / 设置 / 查看状态）
