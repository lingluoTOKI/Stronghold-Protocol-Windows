本轮未上传、未部署。每日三项各 1 分，单人／多人分别累计，同分并列，不按完成时间排名。

每天每榜最多 3 分，一局可完成多项，重复不加分。已有同日成绩不会被新目标覆盖。

## 每日收藏与读取

共 21 枚：基础 1、防守 2、核心 2、核心盟约试炼 8、核心盟誓 8。
完成过的目标永久收藏，单人／多人分开；当日三项完成显示勾选标记，不新增可重复领取的组合章。
迁移保留现存每日完成记录。旧版本未保存且已过保留期的每日章无法凭空恢复；旧组合章保留独立展示，可由仍留存的旧日三项完成记录恢复，不替玩家伪造精确获得时间。

打开挑战页只读本人当天完成项和目标，ranking=0 不排序、不返回他人榜单。点击查看排行榜才读取前 100 条与自己名次；无轮询，手动刷新冷却 15 秒。
七日预告来自服务端；每日收藏点击展开才读。房间提供开局前查看目标与规则的入口。

排行榜沿用已有服务端接受的结算流程，不声称新增全局战斗重演或防作弊保证。本地导入不能上榜。

## 3.25 倍首领血量计分（2026-11-01，本地代码待部署）

按维护者要求，首领血量 **3.25×** 的对局不再整局作废，改为按倍率加权计入**同一张榜**：1× 每个目标 1 分，3.25× 每个目标 3.25 分。一局最多完成三个目标，因此单日单榜上限从 3 分升到 9.75 分。单人／多人仍分榜，同分并列。

- 挡位白名单仍以 `shared/constants.js` 的 `BOSS_HP_OPTIONS` 为准（1、3.25）；其它值一律拒收，下发判定见 `server/lobby.js` 的 `challengeSettlement`。
- 每日去重规则不变：同一目标当天只计一次，跨挡位重复完成不加分。分数分别记入各自的日榜与累计榜。
- 永久成就共用同一条结算凭据校验，所以 3.25× 通关同样推进成就进度。若日后要限定成就只在 1× 计入，需把成就与积分的挡位判定拆开。

**存档格式升级为 version 4。** 积分不再按「目标个数」存，改为 1/100 分的整数刻度（1× 目标 = 100，3.25× 目标 = 325），避免浮点误差；展示时除以 100。日榜条目新增 `w` 字段记录当日加权分。迁移时把旧的累计积分乘以 100、按已完成目标数补齐日榜 `w`，并先写一份 `.pre-weighted` 副本。

**回滚注意：** version 4 是单向迁移。旧程序只认 version ≤ 3，读到 version 4 会判定存档无效并停用排行榜，改用备份同样无效。回滚服务端必须同时还原迁移前的存档（`.pre-weighted` 或 `challenge-backups/` 内的当日快照），否则请勿回滚。
