## 二、第一次玩（素材导入）

1. 不导入素材也能进游戏对局，但美术、语音、特效不完整。
2. 完整素材：到 **QQ 群 1104628970** 群文件下载素材 zip → 游戏标题页「**导入素材包**」→「**选取 zip**」。
   - 约 38,000 个文件 / 1.6 GB，手机需要 2 GB 以上剩余空间。
   - 导入是**本地解压写入浏览器缓存，不消耗流量**；中断后重新导入会自动跳过已保存的文件（断点续传）。
   - 正常的导入界面显示「**已完成 X / Y 个文件**」。如果显示「已接收…浏览器缓存约…」，说明页面是旧版本——**完全关闭页面（从后台划掉）再重新打开**即可。
3. 也可以在标题页点「下载完整素材」直接从服务器拉取（约 700 MB，耗流量）。

## 三、玩法速览

- **一局流程**：确认本局信息 → 轮选策略（40 名分队长，决定初始生命值与规则）→ 每回合【机变 → 休整期 → 作战 → 联防 → 结算】→ 第 14 回合最终攻势 →（满足条件）第 15 回合隐秘核心 → 结算称号。
- **模式**：同盟模拟（2–6 人联机合作）/ 独立模拟（单人，可随时暂停）。
- **难度**：标准 / 险境 / 绝境 / 终极（另有训练、欢乐）。难度越高敌人越强、领袖血量越高。
- **开局 BAN**：基础禁用核心 3 / 附加 4 个盟约；5 人（含 AI）少禁 1 个核心、6 人少禁 2 个（即 6 人局核心 1 / 附加 4）。训练模式不减免。
- **断线重连**：掉线后 **60 秒内**重新打开页面自动回到原座位（同盟掉线期间你的阵容照常自动作战，但不会替你购买；想让 AI 代打请选「暂离（AI 托管）」）。独立模拟同样 60 秒；独立模拟的作战可以按 `Space` 暂停。
- **每日挑战**：每天 3 项目标，每个目标当天首次完成 +1 分、每天最多 3 分；积分进**累计榜**长期累加，单人/多人分榜，同分并列。目标按七天轮换，新一轮仍可得分。
- **收藏**：永久成就 31 枚 + 每日挑战 21 枚蚀刻章，只显示章面，真实获得才点亮。
- **身份恢复码**：一份恢复码同时用于找回每日与永久身份——换浏览器/清空浏览器数据后，用恢复码找回成绩与奖章，**务必保存好**。
- **服务器重启**：对局回到最近一次**休整期**存档，60 秒内重新打开页面接回；作战回合中的进度不落盘，会重打该回合。

小技巧（精选）：前期优先凑出一个能激活的盟约；资金不留到下回合，想要的卡先冻结；看到飞行/近地悬浮敌人留好对空；同盟里和队友分工凑不同盟约；LP 只剩 10 左右优先保完美作战；领袖战单次伤害超过 30 万会被作废（限伤）。

## 四、问题排查 FAQ（机器人按条目回复）

**Q1：页面打不开 / 一直转圈？**
A：① 确认用的是系统浏览器而非 QQ 内置；② 手机网络切换 WiFi/流量再试；③ 其他玩家也打不开就是服务器问题，等公告；④ 服务器状态可在浏览器打开 `https://game.lingluotoki.dpdns.org/healthz` 查看，有 JSON 返回即在运行。

**Q2：提示「服务器繁忙」？**
A：房间数达到上限（64 间）。现在服务器会自动清理无人房间，一般 1 分钟内释放；稍等后重试即可。若持续出现请向管理反馈。

**Q3：素材导入很慢 / 卡在某个数字不动？**
A：① 先**完全关闭页面再重新打开**（从后台任务划掉）——旧版本页面有卡死问题；② 确认界面显示「已完成 X / Y 个文件」（新版标志）；③ 检查手机剩余存储 ≥ 2GB；④ 导入不消耗流量，卡住多半是手机性能或存储不足；⑤ 之前导入的部分不会丢，重新导入会自动跳过。

**Q4：对局突然消失 / 无法接回？**
A：① 掉线超过 60 秒，对局席位已被释放——这局只能重开，下次掉线请尽快回来；② 服务器重启后会回到最近一次休整期存档，60 秒内刷新即可接回；③ 若提示无法恢复（如「对局恢复失败」），该局存档被安全机制拒绝（有人在你之后离开过），只能重开，成绩与奖章不受影响。

**Q5：操作没反应 / 提示 WRONG_PHASE？**
A：刷新页面重新进入。若频繁出现，截图带房间号反馈给管理。

**Q6：成绩 / 奖章 / 排行榜里的自己不见了？**
A：换了浏览器或清空了网站数据。用**身份恢复码**找回（每日挑战页面里有恢复入口）。恢复码没保存的话无法找回，请务必保存。

**Q7：手机屏幕被挖孔/刘海挡住？**
A：设置 →「异形屏适配」，四边滑块可微调，50 为默认。

**Q8：想反馈 bug？**
A：游戏内「设置 → 问题反馈 → 复制诊断信息」，把诊断信息 + 发生了什么 + 房间号/时间一起发给管理或贴到群文件。诊断信息自动隐藏玩家名，不含密码。

**Q9：怎么找到官方玩法细节？**
A：游戏内标题页「玩法说明」和顶栏「S.W.E.E.P. 报告」（盟约报告/策略报告/敌方图鉴）都有完整说明；战场上的地形和装置点一下就出说明卡。

**运维备忘（2026-10-22 起）**：
- 断线重连窗口全部 **60 秒**（同盟/独立/重启恢复一致）；空房 60–75 秒内自动释放，不会再出现「服务器繁忙」式满员。
- 重启时只恢复「进行中对局 + 结算后 60 秒内的回放」；更早的结算回放不再重建。
- 恢复守卫：checkpoint 之后有人离开的对局会被拒绝恢复（防队伍状态错乱），属预期行为。
- 六人局开局 BAN / 血池翻倍 / 悬赏补卡修复已于 10-22 生效；更早开的旧对局保留旧抽签。
- 素材导入缓存（`sp-imported-assets-*`）不会再被页面启动脚本清除。

**已知限制**：存档只支持休整期节点（作战中途重启会回到上个休整期）；玩法插件房不支持恢复；跨代码/内容版本的存档不恢复。
